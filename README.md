# MBTI 性格测评

基于 MBTI（迈尔斯-布里格斯性格分类指标）的轻量级性格测评网页应用。

## 特点

- **20 道二选一题**，覆盖 E/I、S/N、T/F、J/P 四个维度（每维 5 题）
- **纯前端**，零外部依赖，双击 `index.html` 即可运行
- **随机题序**，每次测评题目顺序和选项位置随机打乱
- **本地保存**，结果存于浏览器 localStorage，无需账号
- **响应式**，电脑和手机均可良好显示
- **四维可视化**，结果页展示 16 型人格、四维倾向百分比及四字母含义

## 使用方式

直接在浏览器中打开 `index.html` 即可开始测评。

## 在线访问

- 原生 HTML / CSS / JavaScript（ES6+）
- 无框架、无构建工具、无外部 CDN
